## Job Description

### Overview
We're recreating a classic brain training game (think Lumosity/Peak) with 12 mini-games testing memory, logic, math, and visual skills. 

**The good news:** We have complete technical specifications, TypeScript types, state management, and architecture already built. You're implementing from detailed specs, not figuring it out from scratch.

### What We're Looking For
A senior React developer who can:
- Build 12 mini-games from our detailed specifications
- Implement Canvas-based graphics and animations
- Write clean, tested, production-ready code
- Work independently with minimal management
- Deliver on time with consistent quality

### Technical Stack
- **Framework:** React 18 + TypeScript
- **State:** Zustand
- **Graphics:** HTML5 Canvas + React Spring
- **Build:** Vite
- **Testing:** Vitest + React Testing Library

### What We Provide You
1. Complete game specifications (12 mini-games documented)
2. TypeScript type system (all interfaces defined)
3. State management architecture (Zustand store ready)
4. Project structure (organized, ready to go)
5. Knowledge base (React patterns, Canvas techniques)
6. Testing framework setup
7. Daily support from technical lead

### Your Deliverables
1. **12 Working Mini-Games:**
   - Block Counting (3D isometric rendering)
   - Memory Cards (flip animations)
   - Quick Math (arithmetic problems)
   - Asteroid Sorting (Canvas animation loop)
   - Hexagon Path (SVG + path tracing)
   - Scale Balance (weight logic puzzles)
   - Object Sequence (memory game)
   - Puzzle Pieces (visual-spatial)
   - Pattern Match (shape transformations)
   - Number Sequence (math patterns)
   - Visual Transform (rotation/scaling)
   - Sushi Memory (pattern recognition)

2. **Complete Game Flow:**
   - Main menu with mode selection
   - Smooth transitions between games
   - Progress tracking
   - Score calculation system
   - Results screen with "brain size" classification

3. **Code Quality:**
   - TypeScript strict mode (no `any`)
   - Unit tests for game logic
   - Integration tests for flows
   - Clean, documented code
   - Performance optimized (60fps)

4. **Deployment:**
   - Production build
   - Vercel/Netlify deployment
   - CI/CD pipeline setup
